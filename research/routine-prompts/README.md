# Routine prompt history

The monthly research task runs from a prompt stored in a Claude Code Routine, outside this
repository. That prompt is easy to change and easy to lose, so each version is archived here
when it is replaced, with the dates it was in effect and why it changed.

The live prompt should always match the newest file in this directory. When you change one,
change the other in the same commit.

| File | In effect | Audience |
|---|---|---|
| `2026-09-05-general-audience.md` | Sept 5 to Sept 8, 2026 | General informed reader |
| `2026-09-08-school-models.md` | Sept 8, 2026 onward | Program director at an evidence-driven K-12 funder investing in school models |
